GRID SYSTEM EXPLANATION - Windows 11 Desktop Clone
================================================================================

HOW THE DESKTOP ICON GRID WORKS
================================

The desktop uses a special grid layout that arranges icons from TOP to BOTTOM,
then LEFT to RIGHT (just like a real Windows desktop).


THE KEY CLASSES
===============

1. .desktop-area
   - This is the main container that holds all desktop icons
   - Takes up the full screen height minus the taskbar (48px)
   - Uses CSS Flexbox to create the grid layout


2. Bootstrap Classes Used:
   - d-flex           → Enables flexbox layout
   - flex-column      → Makes items stack vertically (top to bottom)
   - flex-wrap        → When a column fills up, start a new column to the right
   - p-2              → Adds padding around the desktop area
   - gap-1            → Adds small spacing between icons


HOW IT WORKS STEP BY STEP
==========================

1. Desktop icons are placed one after another in the HTML
2. The flex-column makes them stack VERTICALLY first
3. When the screen height is full, flex-wrap creates a NEW COLUMN
4. The new column appears to the RIGHT of the first column
5. This continues for all icons

EACH DESKTOP ICON
=================

Each icon is a fixed size:
- Width: 85px
- Height: 105px
- Contains an image (48x48px) and text label below it
- Has hover effects for better user interaction


WHY THIS SYSTEM?
================

✓ Mimics real Windows 11 desktop behavior
✓ Icons automatically arrange themselves
✓ Responsive - adjusts to different screen heights
✓ Easy to add or remove icons without breaking the layout
✓ Clean and maintainable code


ALTERNATIVE APPROACHES
======================

Instead of this flexbox approach, you could use:
- CSS Grid (grid-template-columns and grid-auto-flow)
- Absolute positioning (more complex, less flexible)
- JavaScript-based masonry layouts (overkill for this)

But flexbox is perfect for this use case!


CUSTOMIZING THE GRID
====================

Want to change how many icons fit vertically?
→ Adjust the .desktop-area height or individual icon height

Want wider gaps between icons?
→ Change gap-1 to gap-2 or gap-3

Want icons to go left-to-right first?
→ Remove flex-column (but this won't look like Windows anymore!)
